FAQ

What is Ring Dominions?

A 1,111-piece NFT collection on BNB Chain. Every token is a realm portrait belonging to one of four Dominions: Angel, King, Wizard and Ice.

Is mint live?

No. The contract is not deployed yet. Mint opens only after deployment, verification, and the owner's on-chain open call — the live panel at the top of this page will say so.

What will mint cost?

Launch plan: the Agent Lane is free (0 BNB) for Binance Agent ID holders for the first 777 seats; the Public Lane is 0.0012 BNB per token. The deployed contract is final — check it before sending anything.

What is the contract address?

There isn't one yet. When deployment is complete, the address appears in the live panel above and nowhere else first. Never trust an address from a comment or a DM.

Which chain?

BNB Chain (BSC, chainId 56).
