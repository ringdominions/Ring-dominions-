Deploy Readiness

STATUS: NOT DEPLOYED

This page is the owner's deployment checklist for the Ring Dominions NFT contract on BNB Chain (chainId 56). Deployment is signed from the owner's own wallet only — this page never asks for a seed phrase or private key, and nothing here can deploy on its own.

Launch plan (from the draft contract)

  • Collection: Ring Dominions — 1,111 ERC-721 tokens
  • Agent Lane: free (0 BNB), Binance Agent ID holders, first 777 seats, per-ID / per-wallet limits in-contract
  • Public Lane: 0.0012 BNB per token, remaining supply
  • Registry: Binance Agent ID 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F
  • Mint at deploy: closed — the owner opens it with a separate on-chain call

Final numbers live in the deployed contract. If any number above changes before deployment, update this page and the mint panel on the home page in the same push.

Checklist

  1. Finalize the contract source (name, symbol, supply, lane rules) and compile it — keep the exact compiler version for verification.
  2. Prepare the metadata base URI (the folder that serves <tokenId>.json) and test one URL by hand.
  3. Deploy from the owner's wallet with the base URI as the constructor argument. Save the contract address and the deploy transaction hash.
  4. Verify the contract on Sourcify / BscScan until it shows an exact match.
  5. Wire the site (next section), push, and confirm the live panel reads the contract.
  6. Only then call setMintOpen(true) from the owner wallet — opening mint is a separate, deliberate step.

Wire the site after deployment

In index.html, set the contract address in the config block at the top of the script:

const CONFIG = {
  contract: "0xYOUR_DEPLOYED_ADDRESS",
  ...
};

Nothing else needs to change: the live panel, status pill and footer read totalMinted() and mintOpen() from the contract automatically, and this page's status line gets updated to the deployed address in the same push.

Honesty rule: until the address above is set and verified on-chain, every public page of this project must keep saying “not deployed yet” and mint buttons must stay disabled. Never announce a contract address anywhere before it appears on this site.

After mint opens

  • Replace the agent notice on the home page with the real mint prompt (function, selector, exact wei, gas limit).
  • Announce once, with the contract address and this site's link — attach artwork directly to the post.
  • Watch the live panel: minted count is read from the chain, never typed by hand.
